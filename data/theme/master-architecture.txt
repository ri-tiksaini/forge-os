  User runs `dev add postgres`  OR  clicks Install in ★ forge-settings (Software Store)

       ├──► crates/forged/src/policy.rs   ──► checks SO_PEERCRED + org.forge.catalog.policy (Polkit)
       ├──► crates/forge-catalog/         ──► loads /usr/share/forge/catalog/*/*.toml + SHA-256
       ├──► crates/forge-txn/             ──► runs batched apt + write-ahead rollback journal
       └──► crates/forged/src/parking.rs  ──► installs zero-RAM socket proxies:
                 ├── forge-postgres-proxy.socket (5432) ──► wakes postgresql on demand (90s idle sleep)
                 ├── forge-redis-proxy.socket    (6379) ──► wakes redis on demand
                 └── forge-mariadb-proxy.socket  (3306) ──► wakes mariadb on demand

6. QUICK COOKBOOK: "IF I WANT TO CHANGE X, EDIT FILE Y"
================================================================================
  • Add a new Color Theme:
      1. Edit `crates/forge-settings/src/model.rs` (add theme hex palette)
      2. Edit `crates/forge-settings/src/ui.rs` (add theme button)
  • Add a new button/icon to the bottom Taskbar:
      1. Edit `/usr/share/forge/waybar/config` (add custom module + on-click command)
      2. Edit `/usr/share/forge/waybar/style.css` (style the button colors/padding)
  • Add a new Keyboard Shortcut (e.g. Win+T):
      1. Edit `data/keymap.toml` + `crates/forge-conf/src/emit_labwc.rs`
  • Create your own system command/tool:
      1. Type tool name in the top bar -> click "+ Create Tool"
      2. Write your script -> "Save & Stage This File" -> "1. Test in Virtual OS" -> "2. Patch Live OS"
  • Undo everything if you break core files:
      1. Open Settings (Win+I) -> About & Repair -> "Factory Core Restore"
         (Restores /var/lib/forge/factory-core/* without touching /home!)

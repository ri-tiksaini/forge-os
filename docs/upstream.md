# Upstream Lineage & Support (Blueprint N6)

Forge OS 1.0 is built on **Debian 13 ("trixie")** stable (`ID_LIKE=debian` in `/etc/os-release`)
using the Linux 6.12 LTS kernel, Wayland compositors (`labwc` 0.8.3 / `sway` 1.10.1), GTK4,
Flatpak, Podman, and `mise`.

- Debian Wiki & Documentation: https://wiki.debian.org
- Debian Package Tracker: https://tracker.debian.org
- All upstream Debian repositories remain reachable and unmodified in `/etc/apt/sources.list`.
